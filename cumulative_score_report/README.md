# 김현수학 누적 성적표

이 폴더는 전달받은 `누적성적표.zip`의 프로젝트를 기존 `combined/score/`와 분리해 정리하는 공간입니다.

## 폴더 구성
- `source/` — Python 소스 보관
- `build/` — EXE 빌드 설정
- `docs/` — 사용법 및 설명
- `release/` — 실행 파일 배포 안내

## 현재 업로드 상태
- 업로드함: 프로젝트 안내, 일부 Python 소스 및 빌드 스크립트
- 아직 업로드하지 못함: 전체 Python 소스 전체와 Windows EXE 바이너리
- 원본 ZIP은 이 대화에 업로드된 파일을 기준으로 유지합니다.

GitHub 연결 기능으로는 텍스트 파일만 직접 업로드할 수 있어 ZIP 전체와 EXE 바이너리를 이 방식으로 그대로 올릴 수 없습니다. 기존 저장소의 다른 파일은 덮어쓰지 않았습니다.
